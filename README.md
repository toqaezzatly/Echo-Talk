## **Project Description**
A chat application enabling users to send and receive messages, focusing on a straightforward communication process without real-time synchronization. 

### **Core Features**:
- Message handling and display.
- Secure authentication and authorization with **JWT**.
- User-friendly interface styled with **TailwindCSS** and **DaisyUI**.

---

## **Learning Objectives**
1. Implement a functional **chat system** without real-time synchronization.
2. Learn secure application development with **JWT-based authentication**.
3. Develop scalable applications using the **MERN stack**.
4. Manage application states effectively with **Zustand**.
5. Gain experience deploying professional-grade web applications.

---

## **Technologies Used**
- **Frontend**: React.js
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **UI Framework**: TailwindCSS, DaisyUI

---

## **Third-Party Services**
- **JWT**: Secure token-based authentication.
- **MongoDB Atlas**: Cloud-based database hosting.
